# ☁️ AZ-104 Practice Exam

A self-built React study tool for the **Microsoft Azure Administrator (AZ-104)** certification exam. Built to reinforce hands-on lab work with randomized practice questions, immediate feedback, and domain-level weakness tracking.

Live demo: *coming soon*

---

## Features

- **25 questions per attempt** — 5 randomly selected from each domain pool
- **40+ questions total** — every attempt pulls a fresh set, no two exams are the same
- **Two answer modes** — immediate feedback per question, or reveal all at the end
- **Explanations on every answer** — right or wrong, you learn why
- **Domain performance tracking** — see exactly which AZ-104 domains need more work
- **Matches real exam structure** — questions weighted by official Microsoft exam domain percentages

---

## AZ-104 Domains Covered

| Domain | Exam Weight |
|--------|------------|
| Manage Azure Identities & Governance | 20–25% |
| Implement & Manage Storage | 15–20% |
| Deploy & Manage Azure Compute | 20–25% |
| Configure & Manage Virtual Networking | 25–30% |
| Monitor & Maintain Azure Resources | 10–15% |
